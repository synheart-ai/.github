# synheart-ai / .github

This repository hosts the **Synheart organization profile** rendered at
[github.com/synheart-ai](https://github.com/synheart-ai).

The profile content lives in [`profile/README.md`](profile/README.md) — edit
that file to update what visitors see on the org page.

For the project itself, see [synheart.ai](https://synheart.ai).
